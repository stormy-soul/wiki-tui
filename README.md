### WIKI-TUI
A simple and easy to use Wikipedia Text User Interface
<br clear="all">

## What's this?

Since the original repo is archived and no longer maintained, this fork aims to add features that i myself wanted and were also requested in the original repo (mainly table and image rendering, as requested in [ISSUE #242](https://github.com/Builditluc/wiki-tui/issues/242) and [ISSUE #240](https://github.com/Builditluc/wiki-tui/issues/240) respectively). I may or may not add stuff in the future that i personally think is useful as quality of life improvements!

[![Stargazers](https://img.shields.io/github/stars/stormy-soul/wiki-tui.svg?style=for-the-badge)](https://github.com/stormy-soul/wiki-tui/stargazers)
[![MIT license](https://img.shields.io/github/license/stormy-soul/wiki-tui?style=for-the-badge)](https://github.com/stormy-soul/wiki-tui/blob/stable/LICENSE.txt)

## What can it do?

It can do everything the original version can, plus image and table rendering. Maybe more stuff in the future!
